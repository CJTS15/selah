# Code of Conduct

Selah follows the [GNOME Code of Conduct](https://conduct.gnome.org/) in
its issues, pull requests, discussions and other project spaces.

In short: be friendly, be empathetic, be respectful, be considerate, be
patient and generous, and try to be concise.

Selah is not a GNOME Foundation project, so the Foundation's Code of
Conduct Committee does not handle reports about it. If someone breaks the
code of conduct in Selah's spaces, report it privately to the maintainer,
[CJTS15](https://github.com/CJTS15), using the contact details on their
GitHub profile.
